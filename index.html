How it works

Global collision view

Every roll number is shown. A row is highlighted only when its allocation conflicts with another allocation.

Change control

Only students or teams affected by a collision receive a Change Topic or Change Project button.

Available topics

Change choices contain only unused topics. The current topic and topics already assigned elsewhere are excluded.

Projects

Changing a project keeps the existing team together. Team membership is not changed through the collision control.
